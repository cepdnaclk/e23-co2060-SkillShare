# Frontend Contract Risk Register

This document outlines structural and behavioral risks identified via direct inspection of the Java backend source code. These risks directly impact frontend integration stability.

| Risk | Evidence (From Source Code) | Impact on Frontend | Recommended Action | Priority |
| :--- | :--- | :--- | :--- | :--- |
| **Recursive Direct Entity Serialization** | FIXED in Mission 19F-13. | Availability and Chat Endpoints now use explicit DTOs. | **RESOLVED** |
| **Ambiguous Timestamp Timezones** | `application.properties` lacks `spring.jackson.time-zone`. Source code uses `LocalDateTime` directly. | Timestamps serialize without a UTC `Z` offset (e.g. `"2026-09-17T15:30:00"`). Frontend components (like DatePickers) in different timezones will misinterpret the absolute time of Sessions, causing missed meetings. | **Team Decision**: Align on UTC globally. Frontend should manually append `Z` when parsing, or backend should configure Jackson. | **HIGH** |
| **Silent WebSocket Message Drops** | `ChatController.processMessage()` catches `UnauthorizedAccessException`, prints to `System.err`, and does not reply to the sender. | A sender who tries to message an unauthorized user sees no error on the frontend, assuming the message was delivered successfully. | **Frontend Fix**: Implement strict client-side validation preventing the UI from attempting unauthorized messages. | MEDIUM |
| **Direct Entity Serialization (Safe but Fragile)** | `SkillController` and `NotificationController` return raw `Skill` and `Notification` entities. | Currently safe because `@JsonIgnore` is applied where needed. However, any future backend dev adding a new relationship will instantly break the API contract. | **Backend Tech Debt**: Wrap these entities in `SkillDto` and `NotificationDto`. | **UNRESOLVED** (Medium Priority) |
| **Missing Pagination Limitations** | `ConnectionController` and `AvailabilityController` return unbounded `List<T>`. | A highly active mentor could have hundreds of connections or slots. Fetching unbounded arrays will bloat payload size and slow down the frontend. | **Backend Enhancement**: Implement Spring `Pageable` on high-volume `GET` endpoints. | LOW |
| **Public Unprotected Writes** | FIXED in Mission 19F-13. | `POST /api/skills/add` is now restricted to authenticated users. | **RESOLVED** |
| **Unresolvable Credit Debt** | Credit logic creates `CreditDebt` when a Mentor cancels without funds, but no REST endpoint exists to read or resolve this debt. | The frontend cannot display "You owe X credits" or provide a "Pay Debt" button. Debt can only be recovered automatically upon future earnings. | **Backend Enhancement**: Implement `GET /api/users/me/debt` and `POST /api/users/debt/pay`. | MEDIUM |
| **Missing E2E WebSocket Tests** | No integration tests using `stomp-websocket` clients exist in `src/test/java`. | The WebSocket pipeline relies purely on unit tests. Real-world STOMP broker routing edge-cases might behave differently in production. | **Backend Tech Debt**: Write true Spring `@SpringBootTest` WebSocket clients. | LOW |
